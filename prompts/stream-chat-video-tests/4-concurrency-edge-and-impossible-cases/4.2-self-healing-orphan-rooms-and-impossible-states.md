**Workflow roster (6 workflows):**
1. **Workflow 4.2.1 (Corner — Self-Heal Path A)** — `Meeting` row exists in Postgres (`streamCallId` set), but Stream call was deleted (`404` on Stream) -> `POST /join` returns `409 ROOM_NOT_PROVISIONED` -> `useGetCallById` auto-calls `provisionAppointmentMeeting` and joins cleanly
2. **Workflow 4.2.2 (Corner — Self-Heal Path B)** — Direct navigation to `/meetings/occurrence-<uuid>` when **NO** `Meeting` row exists in Postgres (`404 not_found`) -> `useGetCallById` extracts `<uuid>`, provisions room, and joins seamlessly
3. **Workflow 4.2.3 (Race Condition)** — Simultaneous double-click & concurrent Consultant + Consultee join burst (`inFlightRef` + `prisma.meeting.upsert` `P2002` idempotency)
4. **Workflow 4.2.4 (Impossible State)** — Corrupt occurrence timestamps (`endsAt <= startsAt` in legacy row) fall back safely to `CORRUPT_SLOT_FALLBACK_SECONDS = 7200` (`2h`) without NaN/crash
5. **Workflow 4.2.5 (Distributed Failure)** — Stream API outage / open circuit-breaker (`502`/`503`) surfaces clean `ServiceUnavailableError` recovery screen without client tree crash
6. **Workflow 4.2.6 (Boundary)** — Cross-midnight UTC session (`[23:45 UTC, 00:45 UTC)`) & JWT `-60s` clock-skew immunization (`iat: nowSec - 60`)

## Workflow 4.2.6: Cross-Midnight UTC Boundary (`[23:45 UTC, 00:45 UTC)`) & JWT Clock Skew (`iat - 60s`)

### Step-by-Step Execution
1. **[Chrome DevTools]** Inspect the JWT returned by `POST /api/meetings/<meetingId>/join` (`token.split('.')[1]` base64-decoded payload).
2. **[Supabase MCP]** Inside `BEGIN; ... ROLLBACK;`, verify `occurrence_no_confirmed_overlap` catches overlaps across midnight (`2026-11-01 23:45:00+00` to `2026-11-02 00:45:00+00` vs `2026-11-02 00:15:00+00` to `2026-11-02 01:15:00+00`).

### Expected Invariants & Assertions
- Decoded Stream token has `iat <= nowSec - 50` and `exp - iat >= 14400` (`4 hours`).
- Cross-midnight overlap is rejected with `23P01` because `tstzrange` operates on continuous UTC instants.
