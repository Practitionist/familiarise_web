# Claude Code skills index

This repository's project skills are organised by domain. Claude Code loads a project skill only from `.claude/skills/<name>/SKILL.md`, one level deep; the folder name is the slash command (for example `/booking`), and each `SKILL.md`'s frontmatter `description` is what makes the skill trigger — it lists every topic and "use when" phrase the domain absorbed, so a question that used to land on a narrower skill still finds the right one. A skill folder may also hold a `references/` directory of supporting files that the `SKILL.md` points at and Claude reads on demand; those are not themselves discoverable as slash commands.
