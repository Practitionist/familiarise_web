## 2. Product & Features

### 2.1 Core Value Proposition

> "Online higher education for working professionals"

upGrad bridges the gap between education and employability by offering university-accredited programs with job placement support.

### 2.2 Program Types

| Program Type | Description | Duration | Price Range |
|--------------|-------------|----------|-------------|
| **Degree Programs** | MBA, MS, BBA, etc. | 18-24 months | ₹3-5 Lakhs |
| **Executive Programs** | Leadership, management | 6-12 months | ₹1-3 Lakhs |
| **Certification Courses** | Skill-specific | 3-6 months | ₹50K-1.5L |

### 5.1 User Journey

```
1. Discover Program → 2. Counselor Call → 3. Enrollment
         ↓
4. Onboarding → 5. Learning Path → 6. Live Sessions
         ↓
7. Assignments/Projects → 8. Assessments → 9. Capstone
         ↓
10. Certification → 11. Placement Support → 12. Job
```

## 10. Strategic Recommendations

### 10.1 Differentiation

Position Familiarise as:
> "The Uber for expert advice - get help NOW, not after a 6-month course"

| upGrad Says | Familiarise Says |
|-------------|------------------|
| "Earn a degree" | "Get answers today" |
| "6-month program" | "30-minute session" |
| "₹2 Lakh investment" | "₹500 consultation" |
| "University certified" | "Learn from practitioners" |
| "Curriculum-based" | "Your questions answered" |

### 10.2 Potential Partnership

**Non-compete collaboration:**
- upGrad handles degree programs
- Familiarise handles on-demand consultations
- Cross-referral for different needs

### 10.3 B2B Opportunity

1. Corporate training packages
2. Team subscriptions
3. Enterprise dashboard
4. Custom expert matching
5. Analytics for HR

## 11. Key Takeaways

### What upGrad Does Well:
1. University partnerships (credibility)
2. Job placement network
3. AI-powered learning
4. Massive scale (10M+ users)
5. Strong B2B business
6. Brand recognition

### Where Familiarise Wins:
1. Flexible, on-demand sessions
2. Expert monetization tools
3. Affordable entry point
4. Multiple service types
5. Real-time communication
6. Creator-first approach

### Strategic Priority:
**MINIMAL direct competition** - Completely different segments:
- upGrad: Long-form education, career credentials
- Familiarise: On-demand expertise, immediate help
