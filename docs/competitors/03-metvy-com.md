## 2. Product & Features

### 2.1 Core Value Proposition

> "India's first multilingual AI-driven professional networking and mentorship app"

Metvy aims to automate the networking experience from need discovery to face-to-face interaction through artificial intelligence.

### 2.2 Product Evolution

| Phase            | Focus             | Description                        |
| ---------------- | ----------------- | ---------------------------------- |
| **2018-2020**    | Networking App    | AI-driven professional connections |
| **2020-2021**    | Pivot to Learning | Added cohort-based programs        |
| **2021-Present** | Hybrid Model      | Networking + Mentorship cohorts    |

### 2.3 Key Features

#### AI Networking Platform:

| Feature                   | Description                                             |
| ------------------------- | ------------------------------------------------------- |
| **AI Matching**           | Connects users based on needs and profiles              |
| **Hyperlocal Networking** | Geo-based notifications when relevant people are nearby |
| **Video Calling**         | In-app video meetings                                   |
| **Leaderboard & Badges**  | Gamification for engagement                             |
| **Eagle Mode**            | Privacy feature to go "off radar"                       |
| **Profile Rating**        | Showcase skills and achievements                        |
| **Job/Internship Search** | Built-in opportunity discovery                          |
| **Calendar Integration**  | Google Calendar sync                                    |

#### Multilingual Support:

### 2.5 Cohort Features

- Live sessions with mentors from top companies

## 4. Technology Analysis

### 4.1 Technical Approach

| Aspect            | Details                            |
| ----------------- | ---------------------------------- |
| **Platform Type** | Mobile-first (Android, iOS)        |
| **AI Layer**      | Need discovery, matching algorithm |
| **Geolocation**   | Hyperlocal networking via GPS      |
| **Languages**     | 8 regional Indian languages        |
| **Real-time**     | Video calling, notifications       |

### 4.2 AI Implementation

The AI works by:

1. Gathering user data (experience, education, skills, interests)
2. Processing needs and preferences
3. Matching with relevant connections
4. Sending notifications when relevant people are nearby
5. Reducing connection steps from 8 to 2

## 9. Strategic Recommendations

### 9.1 Differentiation

Familiarise advantages over Metvy:

1. **Creator-focused**: Tools for experts to monetize
2. **Multiple service types**: 1:1, subscriptions, webinars, classes

## 10. Unique Innovation: Hyperlocal

### 10.1 How Hyperlocal Works

```
User A (Marketing Expert) → Enters coffee shop
         ↓
GPS triggers notification
         ↓
User B (Startup Founder) → Gets alert: "Marketing expert nearby"
         ↓
One-click connection request
         ↓
Face-to-face meeting
```

### 10.2 Relevance for Familiarise

- **Not directly applicable**: Familiarise is for scheduled sessions, not spontaneous networking
- **Potential use case**: Conference/event networking feature (future)
- **Focus instead**: Online-first experience
