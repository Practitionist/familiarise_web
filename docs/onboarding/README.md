# Onboarding

This directory documents how a signed-up user becomes a consultant, a learner or an organisation operator, and everything that follows from that choice until the account is production-ready. Read the documents in order the first time; each later one assumes the vocabulary of the earlier ones.

| Document                                                   | What it covers                                                                                                                                         |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [01-system-reference.md](01-system-reference.md)           | The wizard itself: steps per role, the five validation layers, the transform pipeline, the draft row, the server transaction and its design decisions. |
| [03-availability-contract.md](03-availability-contract.md) | The one rule set every availability write shares, the schedule-type switch guard, the shrink notice, and the profile-completion score.                 |
| [dynamic-tags-strategy.md](dynamic-tags-strategy.md)       | How domain tags are proposed and curated.                                                                                                              |
