# Always-on VM near Supabase ap-south-1 (Mumbai): provider research

This page is research evidence for owner option 3 (a Mumbai VM with DBOS) in [the job-runtime decision record](../decisions/2026-10-31-job-runtime-experiments.md). It is not a decision. Every latency figure below is an ESTIMATE until the Lightsail probe runs, which is pending the owner's AWS login. The earlier internal comparison is [Mumbai hosting, phase 1: costed comparison](./2026-10-31-mumbai-hosting-comparison.md).

**Summary.** Recommended: AWS Lightsail in Mumbai, $24 for 4 GB or $12 for 2 GB, with a static IPv4 that is free while attached, no SLA and 2 TB of egress on the 4 GB plan in Mumbai. Runners-up: EC2 `t4g` and GCP `e2` in `asia-south1`. Ruled out: Hetzner (no India region), Oracle Free, E2E Networks (no small plans) and Azure in Pune (not Mumbai), plus the options whose prices or SLAs could not be verified.

Date: 2026-10-31. Research only. No sign-ups, deployments or repo changes.
Legend: VERIFIED = read from an official page or official price API. ESTIMATE = my inference, not measured. GAP = official page could not be read (JS-rendered, 403 or 404); the figure comes from a third party or is missing.

## Recommendation (one line)

AWS Lightsail, Mumbai (ap-south-1), the $24 plan (4 GB, 2 vCPU, 80 GB SSD, static IPv4 included). It is the only option that sits in the same AWS region as Supabase, bills in INR with GST, includes the static IP, and needs near-zero ops. The $12 (2 GB) plan is enough for Phase 1 alone, and a Lightsail plan can be upgraded in place by snapshot. Verdict on the earlier internal research: CONFIRMED. The $12 and $24 prices and the free static IP match the official page. Two caveats it missed: (a) Mumbai gets half the listed transfer, so 2 TB on the $24 plan and 1.5 TB on the $12 plan; (b) Lightsail has no SLA.

## Why the table's gaps matter little

- Static IP for RazorpayX: only Lightsail and DigitalOcean make it free while the IP is in use. AWS EC2, GCP and Azure each cost about $3.65/mo. Not a deciding factor.
- Payouts need the allow-listed address to be the source of outbound calls. On Lightsail the attached static IP becomes the public address, but confirm by running `curl https://checkip.amazonaws.com` from the VM during the probe.
- Supabase pooler hosts (`aws-0-ap-south-1.pooler.supabase.com`) are IPv4-reachable, so the IPv6-only direct host is not needed.

## Ranked top 3

1. **AWS Lightsail Mumbai, $24 (4 GB), or $12 (2 GB) for Phase 1 only.** Same AWS region as Supabase, 1-3 ms. IPv4 included. INR/GST billing, flat price, automatic daily snapshots. Cons: no SLA, 2 TB egress, CPU is burstable, and there is no managed patching (enable unattended-upgrades).
2. **AWS EC2 t4g.medium Mumbai, about $22/mo all-in (ARM, 4 GB).** Same latency and billing as Lightsail, plus a real SLA, better IAM and monitoring, VPC security groups, and a smooth path to ECS or Fargate for Phase 2. Cons: more moving parts (VPC, EBS, Elastic IP), a $3.65 IP fee, burstable credits (t4g defaults to unlimited mode, which can add CPU-credit charges), and ARM builds needed for the Docker image.
3. **GCP e2-medium asia-south1 (or Azure B2als_v2 in Pune as the alternate).** GCP is in the same city but a different network. Prices could not be read from the official pages, so check the calculator first. DigitalOcean BLR1 is the fallback for simplicity, but at 15-25 ms it loses the latency win that is the reason for moving.

Not recommended: Hetzner (no India region), Oracle free tier (A1 capacity and idle-reclaim risk, USD billing; the allocation was cut to 2 OCPU/12 GB), E2E (no small plans), Utho and Vultr (pricing and SLA unverifiable here), Linode (official page unreachable).

## Recommended probe: AWS Lightsail ap-south-1, $24 plan (medium_3_0 style bundle: 4 GB)

Plan: create one Ubuntu 24.04 instance, attach a static IP, install Node 22 and the Postgres client, then run roughly 500 `SELECT 1` through the pooler on port 6543 and on port 5432 (session mode), plus a transaction of 10 statements. Compare with the 1-3 ms and 62-64 ms figures. Also check outbound IP equals the static IP. Delete the instance and the static IP afterwards.

CLI to log in with: AWS CLI v2.

```
brew install awscli
aws configure sso          # needs IAM Identity Center; otherwise use: aws configure   (access key + secret, region ap-south-1)
aws sso login
aws lightsail get-blueprints --region ap-south-1 | head
aws lightsail get-bundles --region ap-south-1     # confirm the 4 GB bundle id and its transfer quota
```

If the owner has only a root or IAM-user account, `aws configure` with a scoped key (Lightsail permissions) is simpler. The Lightsail console also works without the CLI.

Expected probe cost: Lightsail bills hourly up to the monthly price. $24 / 730 h = about $0.033/h, so a 4-hour probe is about $0.13 and a 24-hour probe is about $0.80. A static IP attached the whole time is free; if left unattached for more than an hour it costs $0.005/h. Data transfer for the probe is negligible against the allowance. Possible taxes (18% GST) are extra. Delete everything afterwards.
