ISSUES
─────────────────────────────────────────────

[1] 🟠 P1 — No "Pending Invitations" section with Accept/Decline UI shown (empty state missing)
The page only shows the "Active Collaborations" section. When there are no pending invitations, there is no empty state section explaining what a pending invitation looks like or how to expect one. A consultant who has never seen the Collaborations page has no idea what "collaborations" are, how to get invited, or what the revenue split means. The page provides no onboarding context for this unique feature.

> **Proposed fix:** Add a "Pending Invitations" section (even if empty) with empty state copy: "No pending invitations. When another consultant invites you to co-host a webinar or class, the invitation will appear here." Include a "Learn about collaborations" link to the Help page.

[2] 🟠 P1 — DECLINED collaboration is completely hidden — no history visible
Andrew has 1 DECLINED and 1 ACCEPTED WebinarCollaborator row. Only the ACCEPTED one appears. There is no "Declined Invitations" or "Past Invitations" section. A consultant who wants to revisit a declined invitation (e.g. reconsider or contact the inviter) has no path. The 1 DECLINED entry is effectively silently discarded.

> **Proposed fix:** Add a "Past Invitations" section (collapsed by default) showing DECLINED invitations with the inviter name, event, and decline date. Include a note "Invitations cannot be re-accepted after declining" for clarity.

[3] 🟠 P1 — No actions available on the Active Collaboration card (no "Leave" or "Message")
The collaboration card shows read-only information but no actions. Andrew cannot: leave the collaboration, contact the host (Aarav Anderson), or navigate to the webinar event. There is no "Leave Collaboration" button, no "Message Host" link, and no link to the associated webinar/class event. The card is purely informational with zero actionability.

> **Proposed fix:** Add a card footer action row with: "Message Host" (→ chats page with the host's channel), "View Event" (→ the webinar/class plan), and "Leave Collaboration" (with a confirmation dialog).

[4] 🟠 P1 — "TECHNICAL SUPPORT" role badge has no explanation or tooltip
The purple "TECHNICAL SUPPORT" badge is Andrew's role in the collaboration, but there is no tooltip, popover, or help link explaining what this role means in terms of access and responsibilities. Does a Technical Support collaborator co-host sessions? Do they see attendee data? Can they upload materials? The role is opaque.

> **Proposed fix:** Add a `?` icon next to the role badge that opens a tooltip or modal: "Technical Support collaborators can co-host sessions and access session recordings. They cannot modify event settings or participant lists."

[5] 🟡 P2 — "TEAM (1)" count appears to exclude the collaborator (Andrew) — count is misleading
The TEAM section shows "TEAM (1)" and lists only Aarav Anderson (the Owner). Andrew is also a team member (the collaborator), so the count should be 2. Either the count only tracks additional collaborators beyond the owner (in which case "1" is correct but confusing), or it's a bug where the authenticated collaborator is not counted.

> **Proposed fix:** Clarify the count: either list all team members including the owner and show "TEAM (2)", or label it "COLLABORATORS (1)" to distinguish co-hosts from the owner.

[6] 🟡 P2 — "No events scheduled yet" in SCHEDULE section has no link to schedule
The SCHEDULE section says "No events scheduled yet" but provides no path to schedule an event. For a collaborator (not the owner), this may be intentional (only the owner can schedule), but there's no explanation of this. The collaborator doesn't know if they can schedule or if they need to ask the owner to.

> **Proposed fix:** If collaborators cannot schedule, add: "Only the event owner can add scheduling." If they can, add a "View Event" button that takes them to the relevant event on the Event Planner page.

[7] 🟡 P2 — Heading hierarchy skips H2: H1 → H3 with no H2 in between
The page goes directly from H1 "Collaborations" to H3 "Active Collaborations (1)" with no H2 sub-section heading. This creates a gap in the document outline that screen readers will flag, and makes it harder to navigate by heading.

> **Proposed fix:** Change "Active Collaborations (1)" to H2 level.

[8] 🟡 P2 — No link from collaboration card to the associated webinar event
The card shows the webinar title "Expert Workshop Webinar" as plain text, not a link. There is no way to navigate from this card to the actual webinar plan or event detail page to learn more about the event you're collaborating on.

> **Proposed fix:** Make the event title a link to the webinar's event detail page (or to the Event Planner entry for that webinar plan).
