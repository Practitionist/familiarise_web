Based on @/prisma/schema.prisma, I want to finish the complete workflow of the consultee registration for any of the 4 events/plans-consultation, subscription, webinar, class. Consultations and subscriptions are first booked and then created. Classes and webinars are first paid for and then joined by consultee. 

Now in more depth:

1. Consultation Workflow:
   - Consultee selects a slot from consultant's availability.
   - Two payment options:
     a) Immediate payment: Slot is confirmed instantly.
     b) Pay later: Consultant must approve, slot is reserved but payment required before consultation.
   - Multiple consultees can request the same slot.
   - First approved consultee gets the slot booked.
   - Appointment slot is created correspondingly.
   - Implement a queue system for parallel requests on the same slot.
   - Add a notification system for both consultant and consultee.
   - Implement a cancellation policy with refund options.

2. Subscription Workflow:
   - Consultee requests a subscription plan.
   - Consultant reviews and approves the request.
   - Consultant creates appointment slots from availability slots.
   - If availability slots are insufficient, new ones are created via calendar UI.
   - Consultee receives notification (dashboard + email) to proceed to checkout.
   - Payment window: 2-3 days or before the event.
   - If unpaid, appointment slots expire but availability slots remain.
   - Implement an auto-reminder system for pending payments.
   - Add option for recurring payments for long-term subscriptions.

3. Webinar Workflow:
   - Consultant creates webinar (creates appointment and availability slots if not present).
   - Consultees must pay to join.
   - Implement a waiting list feature for popular webinars.
   - Add an option for consultees to submit questions in advance.
   - Integrate a live chat feature during the webinar.

4. Class Workflow:
   - Consultant creates class (creates appointment and availability slots if not present).
   - Consultees must pay to join.
   - Implement a progress tracking system for multi-session classes.
   - Add a feature for sharing class materials and resources.
   - Integrate a discussion forum for class participants.
